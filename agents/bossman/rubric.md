# Bossman — rubric

Score each item Bossman adds. An item is **good** when it passes every hard check and most soft ones.

## Hard checks (code can do these)
- [ ] `seen_at` is within this run, and `spike` has a concrete value (a count, a rank, a price move, a filing date)
- [ ] At least one source URL, each fetched this run, with a text snapshot saved
- [ ] `origin` is filled
- [ ] No personal details about posters: no handles, names or locations
- [ ] Not a duplicate of an existing item (if it is, the source was merged into that item instead)

## Judgment checks
- [ ] It is moving now, not just historically notable
- [ ] `accountable_party` names a real company, agency, official or institution
- [ ] `checkable_claim` is something records could confirm or refute
- [ ] `records_trail` points one layer below the headline, at records other outlets probably haven't pulled
- [ ] The subject is not a private individual

## Downstream signal (tracked over time, not per item)
- Share of Bossman items that McLovin later uses in a hypothesis
- Share that end up in a published story
- Distribution across source types: an item stream that is 90% X/Twitter is a blind spot
