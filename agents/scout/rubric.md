# Scout — rubric

Score each scout report.

## Hard checks
- [ ] Every tool call carries a stated reason
- [ ] Every source was fetched this run; every `quote` is found verbatim in the fetched text
- [ ] Every source has a `finding` of supports, contradicts, or unclear
- [ ] Official records were tried before news coverage and public discourse
- [ ] "Nothing found" names the system, terms and date range searched
- [ ] No bot wall was bypassed

## Judgment checks
- [ ] The scout searched for contradicting evidence, not only supporting
- [ ] Records were read correctly: no registry-as-transaction, no title-as-person, no round-number-as-universe
- [ ] Dataset freshness was checked before relying on it
- [ ] Any proposed new hypothesis names the records that would settle it
