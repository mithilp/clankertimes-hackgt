# An identity file read as a payment file

*Real case: February 2025.*

**Claim:** people 150 years old were collecting Social Security; "21 million over 99" were marked alive.

**What was true:** an SSA Inspector General report from July 2023 found 18.9 million Social Security numbers for people born in 1920 or earlier with no death record — but 98% received no payments. About 44,000 were active beneficiaries. The actual number of beneficiaries aged 99 and up was 89,106.

**Why it's bad:** the Numident is an identity database. A missing death date is not a check being mailed. The report explaining this had been public for 18 months.

Source: [FactCheck.org](https://www.factcheck.org/2025/02/trump-musk-exaggerate-scale-of-improper-social-security-payments-to-the-dead/)
